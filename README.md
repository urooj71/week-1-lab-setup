# Week 1 – Project Module 1: Cybersecurity Lab Setup

## Overview
This project documents the setup of a cybersecurity testing lab environment using Oracle VirtualBox and Kali Linux.

## Tools Used
- Oracle VirtualBox
- Kali Linux
- 7-Zip
- VirtualBox NAT Network

## Lab Configuration

| Component | Configuration |
|---|---|
| Virtualization | Oracle VirtualBox |
| Operating System | Kali Linux |
| Network Mode | NAT Network |
| Network Subnet | 10.0.0.0/24 |
| Kali IP Address | 10.0.0.2/24 |
| Gateway | 10.0.0.1 |
| DNS | 8.8.8.8 |
| Internet Connectivity | Verified |
| Shared Folder | Enabled |
| Clipboard | Bidirectional |
| Drag and Drop | Bidirectional |

## Tasks Completed
- Installed and configured Oracle VirtualBox.
- Installed Kali Linux as a virtual machine.
- Created a custom NAT Network.
- Configured a static IP address for Kali Linux.
- Verified internet connectivity and DNS resolution.
- Configured shared folders.
- Enabled bidirectional clipboard and drag and drop.
- Created a virtual machine snapshot.
